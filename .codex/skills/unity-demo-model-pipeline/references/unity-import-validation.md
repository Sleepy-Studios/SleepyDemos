# Unity 模型导入与运行验收

## 静态导入

- 当前 Unity 实例的项目路径、Unity 版本正确。
- FBX Scale、Forward、Up 与项目契约一致，根和正式 Mesh 无负缩放。
- 只导入要求的动画、BlendShape、Camera、Light 和可读 Mesh。
- 正式节点数量、名称、父子关系、Pivot 和材质槽与契约一致。
- 相同视觉部件按要求共享 Mesh；没有重复的包装层或遗留占位模型。

## Prefab 与物理

- 使用既有 Builder 或装配入口，资源地址与序列化脚本引用未变化。
- 施力点、铰链、挂点、碰撞代理和地面净空保持契约值。
- 动态物体不使用不受支持的 MeshCollider；视觉 Mesh 与代理 Collider 职责清楚。
- 可动部件围绕正确轴旋转，不用负参数或额外包装层补偿轴向错误。

## 渲染与视觉

- 材质映射完整，Shader 与 Render Pipeline 相符，没有粉色材质或丢失贴图。
- 检查正反面、法线、阴影、Emission、透明排序、相机近裁剪和主要观看距离。
- 在 Scene 和 Game 视图保留必要截图；需要动效时检查静止、过渡和循环状态。

## 运行与测试

- Unity 编译和 Console 无新增错误。
- 运行目标 Demo 直接相关的模型/Prefab 契约测试和最小 PlayMode 行为测试。
- 从正式入口和允许的 Editor 直启入口各验证一次。
- 验证生成、重载、退出和场景卸载后没有重复实例、失效引用或残留物理对象。

## 交付报告

- Blender 源文件与 FBX 路径、版本、时间和 SHA-256。
- 实际执行的 Builder、测试类/方法和人工场景。
- 已确认的视觉结果、未执行项与仍需人工判断的手感或美术问题。
