## 原始目标与交付

在 SleepyDemos 制作 Windows PC 与 Android 同步交付、两端互通、1–6 人联机的原创赌场冒险。参考 Gamble With Your Friends 的共享资金、限时挑战与朋友互动，原创重心为整蛊、随机事件、协作小游戏与荒诞演出。交付 Windows x64 ZIP、Android ARM64 APK、源码、正式资源、构建配置、维护文档和验证报告。

采用 Photon Fusion 2 Shared，同 App ID / 协议版本跨平台私人房间。先验证香港／亚洲区域，无需自建服务器。首版快捷消息、标记、表情；不包含语音、iOS、商店上架、商业化、公开匹配。Windows 10/11 与 Android 8.0 起。

## 内容目标

核心循环：创建房间 → 朋友准备 → 选择挑战 → 进入区域 → 赚取共享筹码 → 应对事件与整蛊 → 达成额度 → 购买道具 → 推进区域 → 团队选择结局。

四阶段默认每阶段四分钟，标准局约20–25分钟。标准冒险、无尽、单人练习、三个存档槽；按人数配置额度与收益。规则决定概率结果，表现不影响开奖。

## 技术与验收

Hotfix Demo保留全部业务；Core提供通用Photon AOT桥接；Demo专属Editor与资源自包含。复用Hub、YooAsset、场景导航、Core UI、MvcBind，不新增Demo生产程序集。场景唯一主相机，Avatar不含Camera/Listener。

可靠命令经过阶段、余额、库存、权限及重复检查。持久状态复制，RPC负责请求／临时反馈；权威交接不能重复扣款、开奖或支付。准备阶段新加入，冒险中原成员重连；全员退出后可根据阶段检查点重建房间。

PC键鼠和Android摇杆触控共用规则，机台操作面板切换输入。平台元数据／DLL／资源包隔离，离线内置包冷启动，移动端排除Windows原生插件。

P0双平台技术闭环 → P1首个完整局 → P2标准冒险 → P3完整内容 → P4正式美术 → P5跨平台打磨 → P6最终交付。P0成功后才铺开大规模内容。

验证1/2/4/6人、PC/Android混合、弱网、重连、权威交接、至少两台Android真机、连续30分钟。Android骁龙720G／天玑700级720p低画质30FPS，PC GTX1650级1080p中画质60FPS。测试只进已有Tests.EditMode／Tests.PlayMode，Unity Test Runner直接相关范围。
