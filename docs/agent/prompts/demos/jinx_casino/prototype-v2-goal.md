## 参考稿、机台与 Hub

先制作大厅、共享二十一点、Hub 主页面、加载界面四稿，明确构图、物件、材质、灯光；用户确认后制作正式资源，并按同视角对照。

赌场用圆角柜体、毛毡桌、简单金属及少量装饰。三样板各有实体操作与结果；金额、动作、结果在物件附近，详细规则按需查看。按较窄横屏确定构图，手机能看清牌、仪表、按钮，扩大的触区不能重叠。菜单、设置、存档用 Core UI，手柄焦点对应实体按钮；不新增 Android 专属页面或 Prefab。

Hub 卡片显示预览、名称、简介、明确进入按钮，保留有效入口。响应式布局适应窗口与横屏，支持指针、键盘、手柄。进入逻辑收为明确方法，处理重复点击、失败提示、按钮恢复；未接通入口显示未开放。

两种加载统一背景、标题、字体层级、进度条，保持 SetTitle / SetProgress 和真实阶段进度。启动界面热更前可用，切场景界面继续普通 Core View。Prefab 通过 MvcBind 更新引用，不留 UI Builder。
