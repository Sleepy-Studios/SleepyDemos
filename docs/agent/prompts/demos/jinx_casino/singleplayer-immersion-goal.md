## 桌面交互

发现→接近提示→聚焦桌面→选筹码/玩法→确认投入→直接操作→物件旁结果/结算→再玩或退出。

每台保存稳定实例ID、相机挂点、操作目标与状态节点。使用唯一游戏相机/AudioListener，聚焦锁移动，退出恢复位置/视角/输入。未投入草稿可取消；已提交局离桌继续、回来恢复同一局，不取消投入/重复开奖。同类固定桌/轮换桌不得串局。

筹码面额、加减、清空、确认直接操作，不依赖输入数字。投入前显示金额、玩法、收益规则和事件修正。牌面、骰面、轮面、落槽和开门必须与真实规则一致。

## 教学、视觉与输入

首玩动作驱动教学可跳过/重放，覆盖移动/视角、进入/投入/结算、购物/道具、阶段推进。每游戏首次有短示范、目标和错误反馈，随时重看规则。首次教学、暂停、设置暂停逻辑时钟；正常操作及离桌冒险时钟继续。

HUD仅筹码、目标、时间、任务和必要提示。四区通过布局/轮廓/材质/灯光/装饰/动线区分。重评全部现有资源，不以数量代质量。交互覆盖默认、选中、按下、不可用、进行中、成功、失败。

Demo独立Input System配置，Exploration/Table/Menu三上下文；规则只收设备无关命令。探索键鼠WASD/鼠标/E、触屏摇杆/滑动/交互、手柄双摇杆/A。桌面指针点物件或方向导航/A，X次要、Y帮助、LB/RB面额或组，B返回，Menu暂停；拖动提供点击/按键替代。设备提示随实际使用切换并过滤漂移。支持灵敏度、死区、Y反转、可关闭震动。

手柄断连/应用后台清输入并暂停，设备/焦点恢复后仍须明确继续。Core菜单导航与桌面导航分离，避免双提交，不新增EventSystem。
