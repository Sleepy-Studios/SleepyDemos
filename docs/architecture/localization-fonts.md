# 多语言与公共字体规范

适用于项目自有公共 UI 和各 Demo。默认语言为简体中文；需要多语言的界面默认提供简体中文、英文两套对应文案。单个 Demo 已明确只提供中文时，遵守其语言范围，不为字体规范额外新增语言切换功能。

## 公共字体组与默认资产

| 用途 | TMP 字体 | 公共材质 | 维护字符集 |
|---|---|---|---|
| 简体中文与中英混排 | `Fonts/TMP_FontAssets/CN/HarmonyOS_CN` | `Fonts/Materials/HarmonyOS_CN` | `Fonts/Fallbacks/Default_CN_Characters.txt` |
| 英文 | `Fonts/TMP_FontAssets/EN/BebasNeue_EN` | `Fonts/Materials/BebasNeue_EN` | `Fonts/Fallbacks/Default_EN_Characters.txt` |

表中路径相对于 `Assets/LoadResources/`。TMP Settings 的默认字体为 `HarmonyOS_CN`；正式 Prefab 保存所需公共字体和材质引用。

- **普通 Demo 不新增专属或补字字体。** 默认复用上述资产；公共字体映射允许同一种语言配置多个 FontId，也允许多个字体组指向同一资产。新字体作为公共资源维护，不按字体组数量机械复制字库。字号、颜色、对齐由 Prefab 保持，语言映射同时选择配套材质。
- 缺字先加入对应公共字符集，再更新原字体资产。不得为了某个页面或 Demo 新建 `Supplement`、动态补字字体或运行时兜底字库。
- 公共字体使用静态字库，中文、英文资产及外置 atlas、材质更新时保留原路径和 GUID，防止 Prefab 引用丢失。字符不足不能靠更换 GUID 或重建另一套字体解决。
- 新增日语、韩语等现有字体无法覆盖的语言，或明确需要独立字体的设计属于范围扩展，需先确认；确定后作为公共语言资源维护，不默认放入单个 Demo。
- 无法由源字体提供的图标、emoji 等按用途使用 Sprite／图标资产；先核对字符与源字体，不反复生成缺字副本。

字体生产和更新沿用[现有 TMP Font Builder 流程](../runbooks/tmp-font-workflow.md)。默认预设是生产入口；针对既有字体补字时核对原字号、padding、图集尺寸和材质效果，不机械套用其他参数。保存后验证新增字符与旧字符覆盖，运行或测试不能留下动态字库缓存变更。

## 文案与刷新

- 多语言文案按模块集中维护稳定键和中文／英文对应值，复用该模块已有语言入口；不在各页面散落同一文案的翻译分支，不复制第三套语言系统。
- 公共语言服务使用 SO 词表与独立字体映射，字段顺序是 Key、FontId、中文、英文，FontId 默认 0。示例自身的语言工具不能作为项目公共服务使用。
- 菜单、HUD、教程、操作说明、设置、暂停、结算、提示及错误信息均遵守当前界面语言；玩家可见角色、赛道和道具译名保持一致。内部 ID、资源地址、配置键与存档键不随语言变化。
- 动态文案使用完整句式和占位符，避免拼接词序；各语言的参数含义和数量保持一致。数字、日期的显示按实际产品语言要求处理，不影响持久化数据格式。
- 语言仅在 Hub 设置切换。先校验目标资源，再销毁 Hub 相关页面并清理派生展示数据，保存语言后重建 Hub 与设置页；失败恢复旧语言。Demo 运行期间语言固定，新页面与循环条目初始化时查询当前语言。
- Get / Format 只取文案，SetText 按 Key 一次性设置译文、FontId 字体与配套材质。可选 FontId 覆盖的空值表示跟随配置，0 是有效字体组。不建立语言事件、全场景字体扫描或逐文本监听。
- 不以缩小所有字号解决英文变长；按最长实际译文检查按钮、自动布局、换行、省略与安全区。

## 验证与维护

- 字符集是可维护的生成输入，不仅检查当前字体已有字符。新增或修改文案后收集实际所需缺字，合并到公共字符集，确认源字体支持并重新生成。
- `Tests.Module.SharedFontAssetTests` 通过 Unity Test Runner 检查公共中英字体是否直接覆盖各自维护字符集，不依赖回退字体掩盖漏字。
- 有语言切换的界面验证中英切换、首次显示、重开、列表复用以及动态提示；所有页面检查缺字、方框、乱码、溢出和可读性。仅静态资产检查不能代替实际页面视觉验收。
- 字体资源布局见[字体目录说明](../../Assets/LoadResources/Fonts/README.md)；本规范与两个 Agent 入口保持一致，Demo 文档引用公共规范，不复制独立版本。
