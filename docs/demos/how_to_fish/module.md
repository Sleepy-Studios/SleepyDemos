# HowToFish 模块（开发中）

## 当前职责与边界

生产代码位于 `Assets/Scripts/Hotfix/Demos/HowToFish/`，首岛原型已接入 Hub。依赖 Unity、Input System；世界与玩法代码直接位于 Demo 根目录，界面代码放在 `UI/`，不让 Core 反向依赖本 Demo。

- `HowToFishCatalog`：ScriptableObject 内容定义，按区域/鱼饵筛选鱼池，验证稳定 ID 与基本配置。
- `HowToFishSession`：交易、背包、升级、收集及状态通知。
- `HowToFishSaveData` / `HowToFishSaveStore`：验证安全快照，维护三个本地槽。Load 只报告损坏与恢复选项；RestoreBackup 必须来自用户恢复选择。
- `HowToFishFishingState`：独立钓鱼阶段、时长与张力规则，不持有 Unity 场景对象。
- `HowToFishInput`：通过 Core InputActionSession 管理保存模板的副本、上下文松键门闩和单次摇杆死区；设备提示使用 InputDeviceState，绑定 ID 保持稳定。
- `HowToFishWorldItem`：刚体抓取、命中、烹饪与单次消费，按实例 ID 持久化。
- `HowToFishPlayer` / `HowToFishFishingRig`：第一人称移动与交互、实体浮漂/鱼线/鱼获；交互射线排除自己正在抓取的物品，攻击射线仍可命中它。
- `HowToFishBoat`：多点浮力与驾驶，依靠船体碰撞承载物品；深水浮力、双输入驾驶、暂停和离舵已通过定向测试，木船候选已装配，灯塔至森林水域的实际航行已有测试。ExitPoint 必须落在甲板内，不能放在船舷外。
- `HowToFishSpiderCrab`：实体上岸后进入预警、定向冲撞/远距跳跃、硬直循环；活动首领不能抓取，死亡恢复原始刚体约束，逃脱销毁实例。伤害和时长为 Inspector 可调推定参数。
- `HowToFishWorld`：会话、世界实体、输入、存档与导航的所有者；当前看守人链路是首岛任务初版，活动首领阻止保存。
- `UI/HowToFishHudPresenter` 与 `UI/HowToFishHudView/View/HowToFishHudView`：复用 Core UI/MvcBind 的 HUD、三槽存档、暂停和图鉴初版。

## 接入与生命周期

Hub 入口在 MainMenuView 的共享卡片数据中登记；场景编号为 HowToFish = 5，保留 JinxCasino = 4。卡片预览直接渲染自制 FishingBoat 源模型，使用公共进入和失败恢复流程。

当前链路：Hub 卡片入口 → `GameSceneNavigator` 加载首岛 → 世界协调器等待导航稳定 → Core UI 显示存档菜单 → 验证目录和存档 → 创建会话并恢复实体 → 启用输入。混合输入钓鱼交易与保存续玩已有实际 PlayMode 验证。蜘蛛蟹死亡由世界生成独立蟹肉，保持实体手持，交给看守人后消费并发放钥匙。

物品 Initialize 只能执行一次；读档后调用 Restore。活物击杀登记图鉴，物品消费先标记不可重复进入，再执行交易/任务效果。效果抛错时恢复可消费状态。场景卸载须 Dispose 输入、关闭自身 UI、取消异步任务、恢复时间与相机状态。

## 模型制作入口

`scripts/how_to_fish/build_first_island_models.py` 在独立 Blender 后台生成首批候选源模型；共享 `fbx_export.py` 负责源文件保留与坐标转换。`HowToFishAssetBuilder.ConfigureModels` 对本 Demo FBX 设置米制及轴转换，菜单为 `Tools/SleepyDemos/HowToFish/配置模型导入`。该工具只配置资产，不代替 Unity Test Runner 验证。

`Tools/SleepyDemos/HowToFish/生成首岛资源` 保存物品/装备 Prefab、输入模板和目录；已有数值不覆盖。`装配群岛场景和HUD` 创建首岛原型并维护 MvcBind 绑定，已存在的场景不重建，避免丢失手工调整。手写 View 与自动生成 Component 分离，生成物只通过 MvcBind 更新。

现有场景装配会增量加入船、灯塔和看守人视觉模型，隐藏相应占位 Renderer，保留物理代理与交互组件；首岛表面改用灰色岩石材质。已有模型节点不会重复创建。装备装配增量加入右手模型，武器挂点保持原位置。`build_first_island_models.py` 与 `render_model_sheet.py` 可在项目路径后传入模型名，只导出或预览指定项；源模型/视觉候选不是最终还原验收。

存档同时保存装备选择和船上状态（驾驶或甲板站立及相对姿态）；恢复时先恢复船体再恢复玩家，死亡共用同一检查点恢复入口。陆地传送先检测附近地面，为角色胶囊保留 skinWidth 间隙。

首岛不赠送鱼竿：拾蛤蜊交给看守人赚钱后购买。看守人支持 E 交付和实体碰撞交付；蛤蜊补充间隔为推定的 30 秒。五种商品摆在灯塔门上，啤酒可装备投掷，雷达显示已解锁岛屿的方向及距离。HowToFishIsland 定义岸线半径，世界协调器按实际航行更新所在水域。森林已加入水蛭任务与巨型食人鱼初版，免费/初级普通鱼池已接入，其它商店内容尚未完成。

森林湖畔女士使用同一个 HowToFishStation 交付事件，事件携带接收者以区分看守人，支持交互和碰撞投喂。草地三处水蛭沿用 30 秒补充周期；交付进度 forestLeeches 存入三槽快照，每次交付保存，三条换一枚 ModifiedLeech。改造水蛭为消耗鱼饵，只匹配森林 GiantPiranha；战败或鱼饵耗尽可重新收集水蛭换取，避免任务软锁。骨架交付将解锁区域提升至至少 2，不回退更晚进度。

HowToFishGiantPiranha 管理跃击、最多三条活动鱼群和逃脱；由世界 Spawn 登记召唤物，击杀只生成一次骨架，战斗期间沿用活动首领禁存档规则。首领结束清理仍存活且未被抓取的随从，死鱼保留供出售/进食。所有伤害、时长和速度为当前推定，尚未验证完整战斗平衡。森林其它商品、其它鱼种和后两岛尚未完成；沙漠当前规则见下文。

森林枪械已接入既有装备与输入：HowToFishPlayer 区分近战 SphereCast 与枪械逐弹丸 Raycast，墙体会阻挡射击；弹匣数据保存在 HowToFishOwnedItem.ammo，-1 为首次装备初始化值，0 必须原样恢复。换弹仅在游戏时间推进，暂停冻结，切枪、传送或上船取消未完成换弹，不会自动补满。现有 Reload 绑定保持 ID，不重建输入资产。HowToFishEquipmentView 管理后坐、弹匣/枪管组换弹动作及枪口闪光，HUD 显示当前弹量和设备对应换弹键。

森林店面目前提供手枪、霰弹枪、热狗及柜台出售入口；静态陈列、枪械装备和落地 Prefab 分开。店面 NPC、其它商品、枪械配件、最终音效和完整升级曲线尚未实现。

鱼竿与鱼池：免费火腿只由蟹竿使用（褐蟹5、虾4），免费薯条只由普通竿使用（鲭鱼2、雀鳝2、狗鱼1）；付费鱼饵在两种鱼竿间共享完整加权池，普通及可选首领不按所在岛过滤。主线首领仍保留本项目区域门槛。是否需要慢收、等待时长及丢饵概率按鱼饵定义；鱼附着后上岸、取消或脱钩只结算一次，空抛不扣饵，耗尽回退免费饵。普通鱼竿售价3。已核实54种生物的基础血量、价值、基础重量、营养、首领时限及拒收标记保存于 creature-source-data.tsv 并由装配入口导入；基础重量尚不等同于实例随机重量或尺寸。资产测试6/6通过，耗饵输入链路另行验证。

CrabRod 保留当前持续收线张力原型；FishingRod 入水后只有按住收线才推进咬钩并移动浮漂，咬钩后切到逐次按下推进的 PullBack 状态，持续按住不重复增加进度，5 秒无按下逃脱。HUD 分别显示张力或连按进度。慢收速度、连按进度系数和超时为推定参数，后续仍须对照原作手感。

沙漠增量装配仍使用同一 SceneBuilder，独立 DesertTerrain 网格与索引 2，既有首岛/森林地形不复用到沙漠。HowToFishStation 追加 Tourist/GrillMaster 枚举值，游客复用实体交付事件；濒危标记存在生物定义，满额奖励拒绝消费鱼获。河豚死亡时一次性消费首领实体并生成鱼鳍和三块肉，只有鱼鳍推进区域至至少 3。蓝鲨击杀记录用于打火机解锁，hasGrill 与任务标记沿用存档字段。

IHowToFishBoss 只提供 HUD 所需的当前实体、战斗状态、逃脱比例与提示，各首领分别管理行为。Pufferfish 在单位物理根下同步缩放球体节点及碰撞体，半血生成有限时毒区，死亡/销毁清理毒区；BlueShark 使用弧形运动及独立翻滚节点。所有时长与数值为推定。任务自动保存复用 TrySave 的实际结果，保存失败时不以奖励提示覆盖错误。

沙漠模型入口为 scripts/how_to_fish/build_desert_models.py，复用现有导出助手。SMG 复用枪械射击/换弹/弹量保存，只由定义 automatic 决定按住连发；单发枪仍按下射击。食物定义 isCookable 允许独立鱼肉烹饪；持续受热、熟成、焦化及清洗见下文。

岩石岛使用独立 RocksTerrain 网格和索引 3。HowToFishTuna 管理跃击，活金枪鱼允许抓取；死亡后保留完整实体。世界只让岩石岛干地上未持有、未烹饪的死金枪鱼累计诱饵时间，消费一次后生成信天翁；水中、活鱼、熟鱼和另一场活动首领都会阻止触发，暂停冻结计时。

HowToFishAlbatross 围绕诱饵位置盘旋投弹并锁定俯冲点。HowToFishProjectile 在 FixedUpdate 中按抛物线扫掠，最先命中的屋顶或墙体会终止落物，不穿透掩体扣血。鸟的躯干、头和可动翅膀有物理命中代理；死亡或销毁清理未落地攻击，世界消费鸟体并生成一次鸟头和肉块。岛民复用交互/碰撞交付事件，只接收鸟头并保存火山解锁标记。

岩石模型分别由 build_rocks_models.py 与 build_rocks_fish_models.py 制作，仍使用共享坐标导出入口。RocksShop 门窗保持开放，屋顶用静态 MeshCollider 而不是整栋包围盒；商品增量装配且不重复。专业鱼池按饵跨后续区域开放；狙击枪复用单发枪、换弹与弹量存档。火山实体已接入下述任务闭环，赌场与枪械附件仍待实现。


## 火山主线（验证中）

火山位于岩石岛正北方。自制 `VolcanoTerrain.blend` 保存地形与熔岩外观，`VolcanoPlank` 保存登山路线部件，静态碰撞和角色/商店引用保存于同一 Main 场景。模型检查、装配和实战验收分别记录。

科学家接受五条已处理的普通鱼，逐次保存 `volcanoFish`；交满后主动领取鱼桶。鱼桶消耗后可再次交谈领取，避免首领逃脱后失去推进途径。普通弓头鲸使用鱼桶，可由两种鱼竿召唤，尸体完整保留；`HowToFishVolcanoCrater` 只把未烹饪、未手持的完整死鲸交给世界，并在无其它活动首领时消费尸体、生成变异鲸。变异鲸死亡只生成一次鲸鱼鳍和肉块，交付鱼鳍取得军用船钥匙。

`HowToFishWhale` 共用冲撞、跃击和暂停/逃脱生命周期，变异阶段另发射熔岩；`HowToFishProjectile` 复用信天翁的扫掠碰撞，可在落地时生成 `HowToFishDamagePool`。毒液与熔岩使用各自 Prefab 数值和视觉；鲸鱼死亡、逃脱或卸载会清理它拥有的全部攻击物和危险区，原毒区及落物脚本 GUID 保持不变。

军用船船舵在取得钥匙后保存 `hasFinished`，再展示返航面板；继续探索保留装备、金钱和任务状态，读档不会强制再次播放结局。当前画面和战斗仍是初版，不代表正式视觉或独立键鼠/手柄通关验收完成。

## 可选首领与普通鱼池
isMiniBoss 区分可选鱼类与主线首领；可选鱼按所持鱼饵在各岛开放，击杀登记普通和 Drip 图鉴，不发放主线掉落。HowToFishJumpingFish 共用翻车鱼/老狗鱼/哥布林鲨的跃动、计时、接触攻击与死亡恢复；翻车鱼 damage=0，另两种可在空中转向并按各自冷却扣血。Tuna 与 BlueShark 保留原行为组件。主线鲸鱼、食人鱼等区域门槛不变。
baitWeights 为与 baits 顺序对应的可选权重数组，空数组沿用旧 weight；配置验证拒绝长度不符及非正/非有限数值。初级鱼池按 S22 候选表加入稀有翻车鱼，活动首领时改为鳕鱼，避免普通钓鱼偶发无法继续。两种专用饵分别在森林商店和火山补给箱陈列。

环境行为补充：跃动脚本更名为 HowToFishJumpingFish 并保留 MonoScript GUID，BingBong 复用跳跃/接触攻击但不启用首领条或逃脱倒计时；它不会覆盖另一场活动首领。海鸥每个当前岛附近最多补充两只，沿用世界30秒补充计时，不扫描全场景；它读取世界实体集合寻找未持有鱼尸，抓取复用 WorldItem 的物理追随并使用零距离 CarryPoint。死亡或卸载必须松开携带物，死鸟再次释放恢复重力。角色死亡留下独立 PlayerRemains 实体，再走既有恢复安全点流程。图鉴过滤五种环境/隐藏生物，全部首领登记两种图鉴，旧档已击败首领在会话初始化时补齐登记。

武器升级由 Catalog 的逐级伤害/费用配置驱动，Session 按实际交互商店区域限制级别并原子扣款；玩家枪械和近战统一读取配置伤害。近战五岛各开放三级（15级），枪械从森林开始各开放三级（12级），Anvil 与 AmmoUpgrade 分别限制手持武器类别。新增指虎沿用已有装备和存档状态，不另设背包系统。霰弹枪按25颗弹丸、每颗3点基础伤害计算；命中冲量按弹丸分配，冲量强度仍为推定手感。每岛已装配独立砧台，后四岛装配弹药台；新增场景装配必须确认保存和实际交互，菜单执行成功本身不证明落盘。

六种枪械附件由 HowToFishAttachment 标识，按每件 OwnedItem 保存瞄具、枪口、激光和扩容状态。Session.CanBuyAttachment/TryBuyAttachment 统一处理兼容性、实际商店区域、价格、重复购买和禁止降级；World 只转发交互与显示同一规则原因。EquipmentView 使用编辑器保存的配件节点、原装/红点/光学瞄准挂点和激光线，Player 按当前弹匣容量换弹并使用镜头中心射击。瞄准使用 Alternate；手持死鱼时 Use 优先进入持续进食，不开枪。新增字段默认无配件，存档校验继续针对原始 payload 字符串，添加字段不会改变旧档校验和。落地武器通过下述装备栏流程转移完整状态。

装备栏现已接入：SaveData.equipmentSlots 保存稳定栏位中的物品ID，库存记录保存数量/升级/配件/余弹；鱼饵和任务奖励不占装备栏。新档三栏，森林起按5/10/25/50/100购买扩至八栏。没有栏位记录的旧档按既有装备迁移，超过八件的旧原型也保留全部，不丢物品；它不能继续购买扩容。满栏允许一件未收纳装备，继续领取第二件会拒绝，切换或收纳时先找空位，否则将原装备物理放下。

落地装备复制OwnedItem快照，成功创建实体后才移除库存；拾回复制完整状态，避免实体与库存共享可变记录。EquipmentView同时用于枪械物理视觉子节点，但只有第一人称实例驱动瞄准、动画与激光。JsonUtility会将空内联对象恢复为默认实例，WorldItemData.HasEquipment据装备ID区分有效快照；普通鱼不会被误认成武器。输入模板仅增补缺少的Holster/Slot动作，保留旧绑定ID。H/十字键下切换空手，Q/Z或十字键左右切换已有装备，未收纳物可进入空栏；数字键可直接选栏。

### 船只升级
会话保存`boatMotorTier`（0/1/2）与`hasBoatRadar`，缺失字段按初始船兼容。`TryBuyMotor`、`TryBuyBoatRadar`统一处理区域、钥匙、余额与重复购买；世界状态变化和读档时调用船体`ApplyUpgrades`，不生成背包装备。中型森林$230，大型岩石$860，船载雷达沙漠$200。启动延迟由船体FixedUpdate推进，暂停冻结；源推力800/1400/2000采用平方根换算到现有速度参数，这一换算是本项目手感推定。实体雷达通过持久世界空间Canvas绘制当前已解锁岛屿，显示随船位置和航向变化，购买不解锁区域。具体运行验收状态见validation。


### 持续烹饪与进食
HowToFishGrill 的持久触发热区处理实体鱼获，并检查第一人称工具中心是否进入热区；复合碰撞体同一物理步只加热一次。受热程度0至1，.5处售价倍率1.5，1处约.1，中间平滑插值。25秒从生到全焦、1.5秒进食和营养使用同一倍率均为本项目推定，不能当作原作精确时序。烤架停止接触即停热，暂停冻结；烧焦工具浸没后恢复，鱼获不可清洗。第一人称工具使用握持根与尖端中点近似重心，实体工具使用Rigidbody.worldCenterOfMass。

WorldItemData保存受热、玩家持有经历与击杀倍率，旧isCooked仍兼容为.5；OwnedItem同步工具受热，拾取、落地和存档复制同一状态。视觉通过MaterialPropertyBlock保留原材质并渐变褐色/焦黑，排除第一人称手部。售价展示和出售共用CatchValue，查看不增钱。实体出售与烧烤师交付要求玩家拿过，海鸥抓取不算。

沙漠/岩石烧烤师共用任务状态：接受一条死BlueShark或GoblinShark，记录GrillSharkDelivered；再次交谈领取打火机后hasGrill开启两处烤架。旧已解锁烤架继续可用。玩家长按主操作进食，松开或切换装备中断，重复消费由WorldItem.TryConsume保护。

补给供货装配沿用 Product 与 SupplyCrate：蟹竿、热狗和手持雷达五岛；普通竿和初级两种饵森林起；标准两种饵沙漠起；专业两种饵岩石起；科学两种饵火山。椰子仅保留沙漠入口。已有商店不重复生成商品，补给台固定落点按地形射线放置；保存场景契约与实际交互分别验收。

### 致死命中奖励

HowToFishKillScore 记录游戏时间中的真实相机转向、瞄准切换、攻击间隔累计和三秒连杀链；HowToFishPlayer 仅在实际射线/近战命中致死时传入现场数据。远程、近战、爆炸分开计算，互斥瞄准与空中条件不会重复叠加；至少五项时追加惊艳×2。F/右肩键只播放装备翻转，不直接改变价值。爆炸评分规则已具备，炸药实体尚未接入。

鱼获的 styleMultiplier 改为浮点乘积，取消五倍上限，连同 hasBeenHitByPlayer 保存；旧整数倍率仍应可读，由存档测试验证。出售沿用统一 CatchValue 并拒绝非法倍率或溢出，不通过四舍五入各奖励再相加。

自制网格的头部阈值以刚体重心到口部 Hook 的投影识别，Prefab 可调 headThreshold，默认.6是校准推定，不声称使用源网格_headPos。目标离地检查采用下方1.5米内法线朝上的实际碰撞表面；法线门槛.7为本项目斜坡容差。当前定向测试正在覆盖乘算、窗口、首击、连杀、非法值和实弹击杀保存。

### 普通鱼的物理运动

HowToFishFishMotion 由世界生成入口绑定玩家，覆盖普通鱼与巨型食人鱼的召唤物；后者不再由 Boss 重复设置速度或伤害。装配器从 creature-source-data.tsv 写入逐鱼跃动力、追击力、寻水力、空中追击、间隔和接触伤害。持握、死亡和运动学刚体停止驱动；攻击冷却由每个实体维护。BrownCrab/RockCrab/Lobster 使用来源步行速度2.25/2.5/3，两种蟹横行，龙虾正向行走。

自制模型的力到速度比例 movementScale=.5、转向速度240度/秒和接触距离.3米属于待视觉校准参数。寻水每两秒在12方向、4到64米半径内检查实际地形，兼容岛内湖泊；有限方向探测不能保证绕过复杂障碍。入水生死规则、蟹类受阻跳跃、模型肢体动画尚待后续实现；当前组件不是全部生物行为已经完成的证明。

### 首领半血保护

HowToFishBossTransition 仅装配在巨型食人鱼、河豚和变异鲸。共同伤害入口 DamageToApply 同时用于实际扣血及玩家击杀计分，半血首次命中截断到半血后开启保护，避免单次巨额伤害跨过阶段；该截断策略是本项目的阶段保全实现。受保护命中不记录有效玩家命中、不发出伤害或击杀事件。保护按游戏时间计时，暂停会冻结。河豚、变异鲸约3秒来自S29/S30；食人鱼3秒仍为校准推定。活动首领禁止保存，过渡状态不进入存档。

巨型食人鱼常规鱼群按6/12存活上限补缺，每条间隔.2秒，一波完毕后15/20秒再次检查。半血额外群独立计数，当前6条属于资料未公开数量的推定，不能将12误当总鱼数上限。鱼群统一使用普通食人鱼组件；死亡、逃脱及离开场景清理仍活着且未持握的召唤物。河豚按剩余生命连续增大，自制模型比例从.45至2.25，保持来源五倍增长比；物理轮廓仍需视觉校准。

毒区和熔岩区域分别按已核实4秒/.75米、20秒/1.75米配置。它们刷新玩家独立中毒/燃烧剩余时间，投射物命中也调用同一状态入口。状态写入会话存档，旧档缺失字段为0；非法时长、伤害、NaN或无限值拒绝。暂停冻结剩余时间，死亡先清除状态再复活；毒火可并存，同类取较强伤害与较长剩余时间，防止多个区域按帧无限叠加。HUD显示状态及剩余秒数。残留暂用3秒、毒8/秒、火12/秒，均为来源未公开部分的可调推定值，不声称原作精确数值；同类合并规则也属于本项目校准。

河豚持续施力追击并按.5秒接触间隔造成来源34伤害，地面/二阶段/空中驱动力7.5/6/3.5来自字段，但以本项目刚体加速度解释；累计着地.75秒后可向高处玩家起跳，低速受阻1秒也会起跳，跃速7需配合自制模型校准。第一至第二阶段连续五倍体型增长和毒区仍在保护期间继续运行。

变异鲸按来源概率.4/.5或高处玩家条件发起跃击，第二阶段每组3跳，中间实际落地后直接起下一跳，整组结束才有1.5秒落地停顿。空中继续朝玩家施力。普通弓头鲸沿用.4且无半血保护与三连跳。常规熔岩4颗、每颗.5秒，半血另开12颗（数量推定）且可以超过3秒保护；组间6秒、水平跟踪加速度及跳跃速度11均为校准项。鲸体接触采用1秒冷却并对变异鲸施加燃烧。近身/落地爆炸的空间范围和基础伤害仍需正式视觉与战斗验收。
