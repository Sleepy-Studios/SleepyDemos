## 验收原则

- 不通过删减内容清单宣布完成，不用代码存在替代可玩验证。
- 测试经 Unity Test Runner 串行运行，只运行本 Demo 和直接受影响公共模块，不默认全项目回归。
- EditMode 验证鱼池、交易、任务、图鉴、存档及损坏恢复；PlayMode 验证物理交互、状态、暂停、输入切换与清理。
- 键鼠、手柄分别从新档至结局；覆盖死亡、逃脱、落海、缺钱、掉线、退出重进。
- 1920×1080 为画面基准，兼容 16:10、21:9；记录验收机器，以 1080p 60 FPS 为性能目标，报告真实帧时间。
- 编译、自动测试、运行、视觉、性能分开记录；不推断 Hot Reload 是否应用。
