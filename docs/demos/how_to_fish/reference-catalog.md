## 个体重量与尺寸

来源的 `_weight` 是基础重量；`_skipRandomizedWeight` 为1的蛤蜊、水蛭、脚蜗牛不随机。其它生物存在个体重量随机化，售价也受个体尺寸因素影响，但公开资料没有给出随机区间、分布或重量与尺寸、售价的换算公式。当前自制推定为重量倍率均匀分布于0.8至1.2，质量线性相乘、整体尺寸按倍率立方根缩放、售价线性相乘后与其它因素统一取整；Drip独立抽取，不改变重量分布，生命和伤害不随体型改变。

存档保存 `weightMultiplier`，旧档缺字段恢复为1；加载不重新随机，不重复累乘尺寸。新字段只接受当前生成范围，防止异常倍率进入物理系统。旧档的基准尺寸与售价保持默认倍率，但刚体质量改用来源基础重量，可能影响碰撞与爆炸冲量，需通过实际搬运验证。`_ignoreDeathByWater` 仅是已采集的标记，尚没有死亡条件和计时证据；不据此擅自新增入水销毁规则。
