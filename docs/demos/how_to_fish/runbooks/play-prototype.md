# 运行五岛单人玩法原型

当前包含五岛主线、返航结局、可选鱼、武器升级、配件、装备栏与存档初版。它不是完整单人复刻的最终交付；环境、水天空、声音与效果已装配并有定向运行证据，整体正式视听和完整新档通关仍未验收。

## 进入与保存

1. 使用 Unity 6000.3.15f1 打开本任务新工作树。
2. 从 `Assets/Scenes/AppEntrance.unity` Play，点击 Hub 的“渔力全开 · 单人”。
3. 选择存档开始或继续。已有进度的“重开”需再次点击确认；损坏主档有有效备份时按钮改为“恢复备份”。
4. 暂停菜单可手动保存或返回 Hub。存档位于 `Application.persistentDataPath/HowToFish`；集成测试使用独立临时目录，不写个人存档。
5. 海上保存会记录玩家在船上的位置、是否驾驶及当前装备。继续游戏时会恢复到船上，不把玩家与远处的船分开。

不把 Demo 场景加入 Build Settings，不直接绕过导航加载。当前尚未接入 Editor 直启旁路。

先拾蛤蜊，可吃下，也可投给看守人或手持后按交互换钱。攒够 $3，在灯塔木门上购买钓竿。被取走的蛤蜊会重新生长；30 秒间隔为当前推定规则，防止新档把初始资源吃光后无法继续。

首岛蟹竿面向海面：按住蓄力、松手抛竿，咬钩时再次按下收线。持续收线提高张力，适时松开；鱼获到岸后抓取、处理，再交给看守人换钱。购买 $12 啤酒后，可切换到啤酒并投给看守人，或交谈交付，取得空罐鱼饵。击败蜘蛛蟹后，拾取独立蟹肉并交付，取得船钥匙。

雷达售价 $10，切到雷达时显示已解锁岛屿。上船前可选好雷达，再对船舵按交互驾驶。首船停在灯塔南岸，向森林航行需先绕过灯塔岛，不能直接穿过陆地；森林在西北方向。再次按交互只离开驾驶位，会留在甲板上。森林湖边的任务人物需要草地上的三条水蛭，交付后领取改造水蛭作为鱼饵，在湖边钓出巨型食人鱼。击败后将独立掉落的骨架交回，记录沙漠坐标。后续区域入口见下文；首领平衡及部分攻击手感仍为推定。

## G5 环境、声音与效果装配

本轮源码、9个环境FBX、20段原创WAV与水面Shader已合入。模型、赌场/码头、声音及粒子四项精确用例分次通过，五岛1080p画面和爆炸近景已查看；尚未试听，不代表G5/G6整体完成。

1. 正常导入并确认无编译/Shader错误，保存当前Demo场景。装配在非Play状态执行；源文件与生成方式见[模型与表现源契约](../model-contract.md#g5-环境与表现源2026-10-04)。本轮不将旧截图视为新增资源运行证据。
2. 完整增量装配仍用 `Tools/SleepyDemos/HowToFish/装配群岛场景和HUD`：更新环境细节/水天空后，依次复用 `SetupAudio` 和 `SetupEffects`。此菜单也维护HUD、商品和既有资源，运行前保留相关手工改动。
3. 只调整声音用 `Tools/SleepyDemos/HowToFish/装配原创音效`；只调整粒子用 `Tools/SleepyDemos/HowToFish/装配爆炸与火山烟`。两者拒绝未保存场景，检查所需素材并保存序列化引用；保存失败会抛错。不能把菜单调用返回当作保存成功证据。
4. 环境装配会重建工具负责的 `EnvironmentRocks`、`EnvironmentUnderstory`、`EnvironmentArchitecture` 和树下 `BranchedVisual`。不要把无关手工内容放入这些子树；现有岛屿地形、树干碰撞和任务站点不整体重建。赌场放置校验失败时先检查报告，不取消门洞/通道要求；栈桥与建筑实际行走仍待验证。
5. 音频菜单保存10个AudioSource和Director引用，循环WAV按PCM导入；粒子菜单保存八面体Mesh、URP原生粒子材质、两处爆炸发射器与火山口烟。音效和粒子均不新增AudioListener、全局服务或独立天气系统。

最小验收顺序：

- 在首岛复用固定镜头检查海天、岸线和照明；森林检查分枝树/地被与水蛭拾取通道；岩石岛实际走过赌场门口及栈桥接岸处；火山检查登山木板、烟柱遮挡和任务点。另补沙漠近景，不能只用首岛截图覆盖五岛。
- 用真实移动、抛竿/收线、开火/换弹、成功与失败交易、UI确认、驾驶/离舵验证声音。暂停应停止玩法声，恢复循环，返回Hub无残留；耳机/音箱试听音量、接缝和空间定位。事件计数/AudioSource.isPlaying只证明接线，不替代听觉验收。
- 在静音与非静音状态分别点燃真实炸药，检查火团/烟尘；连爆不应搬动先前余粒。暂停期间粒子寿命与位置不推进，恢复消散，返回Hub释放。不能直接调用私有视觉回调代替真实引信路径。
- 通过现有Unity Test Runner按精确用例串行运行直接相关检查，真实范围和结果写入[验证记录](../validation.md)，不默认全量回归。链爆只需0.2秒，应记录同步爆炸/伤害事件，不要跨协程假设短命中间实体仍存在；视觉截图使用独立真实引信，不改变生产引信计时。

## 编辑与验证

- 模型源文件和 Blender 导出入口见 [模型契约](../model-contract.md)。
- `Tools/SleepyDemos/HowToFish/生成首岛资源` 创建持久 Prefab、输入和内容目录。
- `Tools/SleepyDemos/HowToFish/装配群岛场景和HUD` 维护五岛场景、商品/升级台、雷达 HUD 和 MvcBind 绑定。已有地形与岛屿不整体重建；灯塔门上的商品陈列由工具重建，旧商店板与出售柜台会移除。其它场景调整在 Unity 中保存。菜单执行后检查 Console 与场景实际保存，不能仅看菜单调用返回值。
- 字体复用项目的 HarmonyOS 源字体，专属 TMP 资产为 `HarmonyOS_CNHowToFish`，不会修改公共 `HarmonyOS_CN`。
- Unity Test Runner 的 `Tests.Demo.HowToFishRuntimeTests` 检查真实启动与操作链路；具体覆盖和限制见 [验证记录](../validation.md)。

森林木制商店位于登岸后通向湖泊的路上。手枪 $50、霰弹枪 $150，枪械用鼠标左键／RT 开火，R／Y 换弹。弹匣耗尽必须完成换弹，暂停会冻结换弹，切换装备会取消本次换弹；读档保留余弹。柜台可出售处理好的鱼获。已合入原创声音接线候选，试听和完整商店视觉校对仍待执行。

森林商店出售普通鱼竿（$3）与初级饵（$3）。普通竿默认薯条入水后按住左键／RT 慢收，咬钩时松开后再次按下，随后连按左键／RT 将鱼拉上岸；持续按住不会重复推进。默认薯条可钓鲭鱼、雀鳝、狗鱼，蟹竿默认火腿可静候褐蟹和虾。付费饵可由两种鱼竿共用，是否需要移动由所选鱼饵决定。空抛取消不扣饵；鱼附着后脱离按鱼饵概率扣除一次，首领饵必耗，初级普通饵为35%。

沙漠位于森林西北方，中心坐标约 (-440, 0, 430)。商店提供标准饵 $15、标准首领饵 $280 和 SMG $650；SMG 按住开火连续射击，R／Y 换弹。将处理好的颌针鱼、海马或鱼缸鱼交给棕榈树下的游客，换胡萝卜召唤河豚；击败后交回鱼鳍可记录岩石岛坐标，普通肉块不能替代。蓝鲨使用标准首领饵。把拿过的死蓝鲨或哥布林鲨交给沙漠或岩石烧烤师，再次交谈领取打火机。把鱼获放到或拿在烤架上方持续加热，熟成后及时取走；继续加热会焦黑、售价下降。烧焦的工具可浸水清洗，鱼获不能洗回原状。

岩石岛位于沙漠西北，中心约 (-720, 0, 650)，红木商店在南侧平台。店内提供专业饵 $50、专业首领饵 $1,200 和狙击步枪 $3,800；普通专业饵对应十种普通鱼，首领饵用普通竿钓金枪鱼。狙击枪为单发，需重复按下攻击，R／Y 换弹。

击败金枪鱼后不要吃、烤或卖掉它。把完整生鱼放在岩石岛干地上，等待约四秒引出信天翁；金枪鱼仍在手里时不会触发。信天翁盘旋投下落物并俯冲，商店屋顶可挡落物，射击同样会被墙和屋顶挡住。击败后拾取鸟头交给商店内岛民，肉块不能替代；存档会记录火山解锁。

火山位于岩石岛北侧，中心约 (-720, 0, 1040)。南岸军用营地出售科学饵 $500 和突击步枪 $20,000。交给科学家五条普通死鱼，再交谈领取鱼桶，用普通竿召唤弓头鲸。保持鲸尸完整且未烹饪，沿木板路搬到火山口投入，触发变异鲸。击败后交回鱼鳍，领取军用船钥匙；操作军用船船舵返回大陆。结局会保存进度，可以继续原存档探索。

## 升级与配件

各岛商店旁的砧台出售指虎（$24）和小刀（$45，首岛仍在灯塔陈列）。手持近战武器对砧台交互，每岛开放三级锐度，共15级。森林起的弹药台为手持枪械开放每岛三级弹药升级，共12级；提示显示当前枪械、下一级伤害与费用。本岛升满后需要前往后岛。

配件箱按手持枪械计价：森林有激光，沙漠加入红点、补偿器和扩容，岩石加入瞄准镜与消音器。瞄具和枪口件各保留一种；消音器不能降为补偿器，霰弹枪不支持扩容。装扩容后正常换弹才能填满新容量。按住右键／LT 瞄准；手中拿着死鱼时，按住左键／RT完成进食；松开或切换装备会中断。各项运行验收状态以[验证记录](../validation.md)为准。

新档有三个装备栏，鱼饵和任务奖励不占栏位。森林起的背包模型陈列台依次以$5、$10、$25、$50、$100扩至八栏。满栏新买的装备会暂留手中，HUD提示“手持未收纳”；切换时有空位就收纳，无空位则物理放下。先处理手中的未收纳装备才能继续领取其它装备。G／LB可投下当前装备；拾回后保留升级、配件和余弹，落地装备也进入安全存档。旧原型的无上限背包会完整迁移，已有物品不会因新容量规则被删除。

船只升级陈列台从森林起出售中型马达（$230），岩石起另售大型双机（$860）；可以直接从初始升级到双机。上船启动初始马达需1.6秒，中型和双机需0.7秒。沙漠起可购买船载雷达（$200），安装在船舵旁，不占装备栏、也不替代任务坐标；屏幕数字对应已解锁的五岛编号。升级状态随存档恢复。

## 人物服装

暂停后进入“衣柜”，点击或用手柄方向键选择服装，查看下方条件后选择“穿戴”。锁定款仍能查看，默认可穿泳者、比基尼、渔夫和水手。成功选择立即保存到本机共享档案；切换航程不会重置，已有遗体保持死亡时服装。返回按钮回到暂停菜单并恢复入口焦点。

首次接入新服装资源时，先执行“配置模型导入”，再执行“装配群岛场景和HUD”；该入口生成服装Prefab、图标引用和衣柜绑定。当前运行与视觉验收状态见[验证记录](../validation.md)，解锁来源及限时计数约定见[人物服装目录](../outfit-catalog.md)。

## Drip与水下炸鱼

- Drip生物显示浅白淡粉变体，熟成和焦化仍会覆盖颜色；保存恢复不改变共享材质。该统一配色强度为项目推定。
- 炸药在岸外水下引信到期后，从最近已解锁岛的普通鱼池生成一条非Drip活鱼；岸内或水面上不产鱼。数量、鱼池和范围为自制补缺；新鱼仍会受到后续爆炸伤害。

## 操作设置

在初始菜单或暂停菜单选择“操作设置”。先调整鼠标/手柄灵敏度、死区和反转，再选择设备及陆地/驾驶组修改按键；分页包含该组动作和通用暂停/图鉴。点击一行后按新键，Esc或手柄取消键放弃，15秒未输入会取消。设备不匹配或与同场景动作冲突时不会改掉旧键。

“恢复默认”只预览默认配置；“取消并返回”或退出快捷键恢复进入前状态。“保存设置”才持久化到本机，跨三个航程槽、Hub往返和后续启动生效。若提示设置损坏，原记录仍保留，明确保存后才替换。
