# 沉浸样板视觉与交互规范

此文为S1设计合同，当前不代表已装配或视觉验收。

## 视觉

主题为荒诞机械游乐场：旧游园黄铜机械、深蓝结构、奶油铭牌、薄荷灯带与梅红奖励。色板：背景#162438、结构#283B50、奶油#F4E4C2、铜金#C49A53、薄荷#64D7BF、梅红#D75C8C。危险同时用形状/文字，不能只靠红绿。

主视觉为真实机台和空间，避免满屏功能按钮。大厅13.2×12.6米，入口至中央圆形地毯形成主轴；三台沿弧线分布，后景为机械大奖装置，侧面售货柜台、壁龛、垂直管线。使用低矮导视、拱框和高低台制造层次，避免四面盒墙换色。灯光先保证手牌与按钮可读，再用局部发光强调；移动端优先烘焙与共享材质，禁止堆实时灯遮盖粗糙造型。

屏幕参考720p：标题32、次标题24、正文20、辅助18；保持对比、中文回退和安全区。桌面铭牌须按实际聚焦截图检查字号，不按世界单位猜。触屏有效命中区域至少约48逻辑像素，窄按钮扩目标但不重叠。

筹码以颜色+数值区分10/50/100；卡牌角标双向、点数及花色真实一致；轮面六种符号不能只用颜色区分。世界空间Canvas仅用于具体机台的铭牌/屏幕，主要按键和牌/杆/筹码为场景对象。

## 实体状态

目标默认有清楚形状，选中加亮边缘/指示，按下小幅位移与短音；不可用同时给原因，进行中锁重复操作但允许离桌。成功出币/灯光与简短音效，失败机械咳嗽/暗灯但仍可读结果。禁止每帧实例化材质。

Slots：投币面额→明确确认→实体启动→逐轮停到真实符号→出币。Blackjack：筹码确认→逐张公开发牌→要牌/停牌→庄家翻牌→收付；背面不能提前泄露隐藏牌。Levers：确认→NPC就位→灯窗→玩家杆/NPC杆实际动作→计分，助手节奏可见。

## HUD、菜单和教学

探索HUD上沿左筹码、中央阶段目标、右时间；下沿仅就近提示及紧凑道具栏。桌面显示该局金额/规则修正/状态，结果优先在机台铭牌。菜单为统一Core View，清晰主次按钮、初始选中、手柄焦点和返回路径；不常驻按钮墙。

教学按实际操作状态推进：转视角→走近→聚焦→选筹码→确认→操作→读结算→离桌→购物/道具→推进。可跳过及重放，失败原因短句提示，不要求重复扣款来通过教学。

Xbox：A确认、B返回、X次要、Y规则、LB/RB切面额/组、Menu暂停。方向焦点按稳定NavigationOrder，跳过不可用目标；拖动有按键替代。键鼠/触屏采用同目标命令，不分叉规则。
