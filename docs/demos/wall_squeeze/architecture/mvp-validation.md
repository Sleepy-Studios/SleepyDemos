# 《夹爆它》玩法验证案 v0.2

## 目标和边界

验证“拖墙是否舒服、成群夹爆是否爽、怪物夹法是否带来变化、保护住户是否带来判断与救场”。可从 SleepyDemos Hub 进入、暂停、重试、依次切换六个短关卡并返回 Hub。

玩家没有场内角色，直接操纵房间。本版新增顶墙怪、钻缝怪、固定隔墙和单关倒计时。保留单轴拖墙；不增加装备、成长、剧情、计分、随机地图、联网、动态刷怪或复杂寻路。

## 对象和操作

| 对象 | 规则与识别 |
|---|---|
| 固定黑墙 | 不可移动，无箭头 |
| 横向滑墙 | 只沿 Y 轴移动，中央白色 ↕ |
| 纵向滑墙 | 只沿 X 轴移动，中央白色 ↔ |
| 普通红怪 | 轴向游走，能被推动、压扁、压碎 |
| 顶墙怪 | 红体、黑侧护甲；X 轴不能压缩，须上下夹碎 |
| 钻缝怪 | 薄红体、黑双横纹；尺寸 0.8 × 0.4，移动速度为普通的 1.8 倍，可穿净高 0.5 的水平窄道 |
| 蓝色住户 | 不自主移动，可被墙推动，压碎则失败 |

鼠标按住滑墙拖动、触屏单指拖墙，只取允许轴的位移，释放停止。单一指针持有一面墙，其他指针不接管。按下前先排除 UI 命中，墙命中范围适当宽于可见范围。

键盘 Q/E 切换墙，WASD 或方向键移动选中墙；手柄左右肩键切换墙，左摇杆沿允许轴移动。实际动作绑定和提示一致。当前选中墙的箭头使用浅灰矩形底框。暂停、失焦、断连、重试、退出及设备切换取消拖动和旧输入；恢复须明确继续，旧按键须释放。

## 推动、压缩和死亡

1. 单面碰墙只推动，不死亡。滑墙沿允许轴推动方块，接触其他方块时传递成推链。
2. 只有滑墙推进造成的推链在同一轴连接到另一面墙或房间边界、无法退让时，才产生压缩。怪物自主游走不能自行压扁对象。
3. 压缩仅改变受压轴尺寸，另一轴保持不变；推链分配需要缩短的尺寸并遵守各怪物轴下限。普通/钻缝的下限为 0.24；顶墙怪 X 下限为原始宽度 0.8。只有可缩短的轴到达下限且有真实两侧支撑，夹持满 0.12 秒才判死。墙停止但夹持仍在时继续计时。
4. 撤墙解除夹持即清零计时。方块恢复到当前空隙允许的尺寸，不能为了恢复原尺寸挤穿墙或其他对象；有足够空间时恢复原状。
5. 滑墙不能穿过固定墙、其他滑墙或未死亡的受压方块；接触时可停止并回撤。连续碰撞须覆盖推链与墙互阻，不能仅检查移动终点。
6. 每次规则步完成全部移动、压缩和死亡后统一判断结果。任一住户死亡优先于“消灭最后怪物”的胜利。
7. 死亡移除碰撞并释放空间，同帧多个死亡合并反馈与计数；每只怪只能死亡一次。

红怪使用简单轴向游走，每秒换向，遇阻转向，不做逃跑 AI。每次重试恢复相同种子、初始状态及布局。重复种子不意味着玩家可以任意等待后仍使用同一解法。

## 六个验证场景

共用一个保存的玩法场景，以关卡数据切换。房间外缘为固定墙，表中的墙跨度是长边范围、轨道范围是中心坐标范围。

| 场景 | 布局与初始对象 | 验证目的 |
|---|---|---|
| ① 一墙夹一排 | 纵墙 x=8，跨度 y=0～9，轨道 x=2～15.65。红怪 (12,1.5)、(13,3.5)、(12.5,5.5)、(14,7.5)。无住户 | 向右聚怪，体验多个压碎 |
| ② 两种方向 | 纵墙 x=10，跨度 y=0～5.4，轨道 x=7.5～15.65；横墙 y=6，跨度 x=0～6，轨道 y=0.35～8.65。红怪 (2,2)、(4.5,3)、(12,2)、(14,4)。无住户 | 箭头、选墙、两轴移动 |
| ③ 先移开住户 | 纵墙 x=1，跨度 y=3～5.4，轨道 x=0.35～15.65；横墙 y=6，跨度 x=0～7，轨道 y=0.35～8.65。住户 (3,4.2)，红怪 (2,1.4)、(4,1.4) | 先右推纵墙移开住户，再下推横墙夹怪 |
| ④ 顶墙转向 | 纵墙 x=8、y=0～5.4；横墙 y=6、x=8～16。顶墙怪 (12,2)、(14,4) | 侧推被护甲挡住，撤纵墙到 x=7.5 后下压横墙 |
| ⑤ 窄道追捕 | 短纵墙 x=4.1、高 0.44，沿 y=4.5 右推；入口 x=4～6 净高 1，后段 x=6～16 净高 0.5。普通 (5.2,4.5)，钻缝 (8,4.5)、(12,4.5) | 普通在入口被夹，薄怪穿道后在末端被夹；固定墙参与真实碰撞 |
| ⑥ 限时救援 | 救援纵墙同③；横墙跨度改为 x=0～7.4；固定竖墙 x=8、y=0～3.4；普通 (1,1.4)/(5.4,1.4)、顶墙 (2.5,1.4)/(6.3,1.4)、钻缝 (3.6,1.4)/(4.5,1.4)、住户 (3,4.2)，限时 35 秒 | 先将纵墙推到 x=7.65 移开住户，再下压横墙处理六只混合怪 |

第三场景推荐纵墙推到 x=7.2：中心 x>7.12 才完全离开横墙跨度，住户随推至约 x=7.72。连续最大速操作约 3.1 秒可完成救援及夹击，须通过真实规则测试确认。原草案第二怪 (5,2) 容易进入救援墙范围，已改为 (4,1.4)。不增加看不见的怪物游走限制。

概念图右侧“安全”标记仅帮助理解，不给予住户无敌效果；继续过度向右挤压仍会失败。关卡可为可解性调整坐标，但不能暗改碰撞或游走规则保证胜利。

## 流程和反馈

- 怪物全灭且住户活着胜利；住户死亡或限时结束失败。同一规则步按住户死亡、全灭、超时的顺序判定。结果冻结模拟，暂停不消耗倒计时。
- 胜利提供下一场景、重试；失败提供重试；最后一关提供重试、返回 Hub。
- 暂停提供继续、重试、返回 Hub。重试复位墙、方块尺寸、随机种子、计数、夹持时间、指针和演出。
- HUD 按概念图恢复粗黑分格：标题、剩余、保护、关卡与倒计时、暂停；底部为三种怪物图例、夹法、当前设备操作提示和重来。群夹短时显示“一夹 N 只”，无计分系统。
- 压碎使用少量轴向矩形碎片、短促音效与短震动，同帧多杀合并反馈。不加镜头震动或全屏闪烁，保持空间判断清晰。

## 美术方向

参考 [最新概念图](../art/gameplay-concept.png)，正式画面严格使用纯色平涂而非图中的微弱明暗。固定俯视，无透视、厚度、渐变、阴影、纸感或纹理。

米白 #F4F1EA、黑 #000000、红 #D0302A、蓝 #1D3F8C、浅灰提示；黄色 #EBC226 仅用于按钮按下反馈。构图不对称且保持留白。所有物体、碎片和动画沿横竖，直角无弹跳或旋转。方向箭头允许尖角作为可读性例外。

普通怪使用红方块与黑色矩形眼嘴。特殊怪的特性靠轮廓与标记表达，表情只负责情绪：顶墙怪的侧护甲对应横向不可压缩，钻缝怪的薄体与双横纹对应快速穿缝，标记受压时保留。

## 工程约定

`WallSqueeze` / `wall_squeeze`，玩法和业务 UI 属于 Hotfix Demo，不新增生产程序集、通用物理框架或 Core 专属业务。规则模拟、场景表现、输入消费与 HUD 按职责拆分。轴对齐矩形规则处理连续位移、推链与压缩，不以刚体力模拟压扁。

复用公共输入路由 GameplayInputRouter、菜单作用域、暂停与设备识别；InputActionSession 本身不包办断连、暂停或震动。动作资产保存为 Data/PlayerInput.asset，沿用现有资产命名规范。真实动作转换成选墙与墙的轴向目标，业务不能复制设备底座。

世界为正交相机与平面形状；HUD 走现有 Widget，暂停/结果为独立 Modal，通过 UIManager 管理。场景、Prefab、关卡资产为真源，生成后移除一次性 Builder 和 meta。

按现有 GameSceneId、GameSceneCatalog、Hub、GameSceneNavigator 与 YooAsset Demos Collector 接入，支持现有 Editor 直启。场景不加入 Build Settings，不直接绕过导航加载。退出释放输入、UI、资源与事件。

## 验收标准

只通过 Unity Test Runner 运行本 Demo 相关行为测试，不默认全量回归：

- 单面接触只推动；被困持续受压判死；撤墙计时清零、安全复原。
- 推链、多怪同帧死亡、墙互阻、高速及不同步长无穿墙或重复计数。
- 住户死亡优先、暂停冻结、重试完整复位。
- 六关保存资产参考路径可完成；新增护甲正确轴、薄体通缝、固定墙与倒计时规则验证。
- PlayMode 验证真实资产、轴向约束、UI 指针阻挡与取消持有、进入/退出生命周期。

编译和 Console 通过 Unity Editor；不使用 dotnet/MSBuild 或第二个 BatchMode。运行测试不是确认 Hot Reload 生效，不主动检查热重载或声称新补丁生效。

人工体验必须确认：六关能完成、能一次夹碎至少三怪、首次使用者能读懂箭头与怪物图例、误夹住户和超时有清楚失败反馈、三端操作入口可用、Hub 往返没有残留。模拟设备与真实硬件分开报告。

最终记录拖墙手感、群杀爽感和保护住户乐趣。自动测试不能证明好玩；若核心体验不成立，优先调速度、受压时间、反馈、布局，不增加成长系统或新怪掩盖问题。
