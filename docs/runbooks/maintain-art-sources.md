## 存放位置

本机美术源目录为 `D:\Unity\Unity_Project\SleepyDemos-ArtSource`。它独立于游戏仓库，不是 Unity 工程，也不参与 YooAsset 采集。正式 FBX、Prefab、Sprite、材质和音频继续保存在游戏仓库中。

迁移保留原始相对目录：

| 源目录 | 内容 |
| --- | --- |
| `ArtSource/` | 赌场 Blender、生成脚本、概念图和公共图标 SVG |

`source-manifest.json` 记录迁移时每份源稿的相对路径、大小及 SHA-256。迁移共 366 文件、53,841,343 字节，包含搬豆工源目录的 `.meta`；复制后逐份哈希一致才删除游戏仓库原稿。该清单只描述迁移快照，修改源稿后应重新记录新版本。

## 修改和导出

1. 在美术源目录编辑需要的 `.blend`、原图或脚本，保留挂点、轴向、米制及对应 Demo 的模型契约。
2. 既有生成脚本依赖游戏仓库的相对路径。运行前，将所需源子目录从美术目录复制回当前游戏工作树的同名位置；这些目录已加入 `.gitignore`，不重新提交源稿。
3. 使用既有脚本输出到本 Demo 的 Library 候选目录，或按该脚本明确的正式导出入口处理。不要直接在独立美术目录运行依赖游戏工作树的脚本，否则输出位置会不正确。
4. 在 Unity 导入候选，验证实际轴向、尺寸、挂点、材质及直接受影响的功能，确认后替换正式资产。更新现有资产时保留 `.meta` 和 GUID。
5. 将编辑后的源稿同步回独立美术目录；清理游戏工作树中本次恢复的源稿。已有源稿先比较或另存，不用整目录覆盖未知版本。

普通游戏运行、Player 构建和 Unity 契约测试只依赖游戏仓库中的正式资源，不要求本机存在美术源目录。文档中的 `ArtSource` 路径均为美术目录内的相对位置；旧验证记录保留原始路径作为历史事实。

## 验证边界

迁出源稿不改变运行资产，也不会减小游戏包或清除 Git 历史中的原稿。源稿迁移验收是文件完整性和引用检查；重新导出的资源仍须进行相应 Unity 验收。
