# 调试和整定 DroneFlight

## 适用场景

- 首次让基础几何体四旋翼稳定起飞。
- 修改质量、机臂长度、电机、Rotor 位置或控制参数。
- 排查高频振荡、缓慢摆动、漂移、推力饱和、挂载下沉或 Joint 抖动。

本 runbook 随实现逐阶段完善。当前只定义裸机 MVP 的调参顺序、必须遥测和验收口径，不提供未经实测的“万能 PID 参数”。

## 前置条件

- Unity 打开的是 `SleepyDemos`；正式 UI 试玩从 `Assets/Scenes/AppEntrance.unity` 启动，经 Hub 进入 DroneFlight。直接打开 Demo 场景只用于物理夹具或局部排障，不提供完整 UIManager 宿主。
- Rigidbody 质量、重心、Collider 和四个 Rotor Transform 已确认。
- 固定物理步长保持基线 `0.02 s`，没有先修改全局 Physics Solver。
- 无风、无载荷、水平地面，机体以零速度和水平姿态开始。
- 调试面板显示目标值、实际值、误差、P/I/D、输出和饱和状态。

## 调参顺序

### 0. 先选择普通或高级设置

1. 不熟悉 PID 时使用“普通设置”，优先调额定载重、满载动力占用、电机响应速度和 Profile。
2. “额定载重”表示长期稳定工作区；“最大载荷倍率”只扩大抓取许可范围，不会凭空增加当前质量或电机推力。
3. “满载动力占用”越接近 100%，挂载额定重量时越吃力；默认 90% 会保留约 10% 理论动力。
4. Profile 负责目标速度与操作上限，不能用降低 Normal 速度来伪装重载吃力。
5. 只有需要直接修改质量、RPM、推力系数、反扭矩和完整 PID 时才进入高级设置并选择“手动物理参数”。
6. 卷扬收纳长度也位于普通设置；它只决定腹部停靠长度。机载抓斗质量在普通页只读显示为默认 `0.05 kg`，需要修改时进入高级设置。
7. 设备质量始终属于整机：收纳时合并进无人机主 Rigidbody，部署时等量转移到唯一抓斗 Rigidbody。F3 的“主刚体质量 + 当前悬挂设备质量”在收放过程中应恒定；它不占用额定载重和最大载荷门禁。
8. 按 `J` 后卷扬在 FixedUpdate 缩放无质量吊索长度；部署拆分继承机体挂点速度，空载回收只有进入位置/相对速度停靠窗口才合并。若放出仍掉高，先检查恒定总质量、Joint 锚点和总升力，不要通过虚增额定载重补偿。
9. F3 的“当前真实载荷”在抓取成功后立即来自被抓物体 `Rigidbody.mass`；“飞控承载载荷”由地面支持力下降比例连续接入。载荷连续三个物理步失去外部支撑后再平滑稳定到完整质量，重新落地时反向卸载；它不读取 `Joint.currentForce`。

### 1. 先验证物理和符号

1. Disarmed 时确认四电机推力为零。
2. 仅增加 Collective，四电机应等量增加。
3. 分别给正 Roll/Pitch/Yaw 小命令，核对四电机增减方向。
4. 确认推力箭头沿每个 Rotor 局部 `+Y`，反扭矩旋向与配置一致。
5. 确认悬停总推力理论值约为 `mass * 9.81 N`，并且最大总推力高于重量。

任一符号错误时先修 Rotor 几何、旋向或控制分配矩阵，禁止通过负 PID 参数“调回来”。

### 1.5 控制分配器

1. 用真实 Rotor 局部位置、局部 `+Y` 推力方向和旋向建立有效性矩阵，单位必须是 N 与 N·m。
2. 未饱和时检查分配后的总推力和三轴力矩能重建目标值。
3. 制造饱和时先确认 Yaw 比例下降；只有 Yaw 与总推力平移仍不足时，Roll/Pitch 比例才允许小于 1。
4. 分配符号正确后再进入 Rate 调参，禁止用 PID 掩盖矩阵错误。

### 2. Rate 环：P → D → I

1. 禁用外层姿态、高度和位置环。
2. `I=0`、`D=0`，从小到大增加 P，使实际角速度能够快速跟随目标。
3. 若出现持续高频振荡，降低 P；不要先增加 Rigidbody angular drag。
4. 增加 D 抑制超调和快速振荡，同时观察 D 项噪声与滤波。
5. 最后增加少量 I，消除稳态偏差，并验证输出饱和时积分不会 wind-up。
6. Pitch、Roll 分别验证；只有机体完全对称时才共享参数。Yaw 单独调节。

### 3. Attitude 环

1. Rate 环稳定后再启用姿态环。
2. 从小目标角开始，确认 Quaternion 最短旋转方向正确。
3. 增加姿态增益，直到回正速度合适且不会把 Rate 环推入长期饱和。
4. 测试接近 ±180° Yaw 和中等 Pitch/Roll，不得出现 Euler 跨界跳变。

### 4. 三轴速度和位置环

1. 使用 `F = m(a - g)` 生成目标推力；先调 Z/Y/X 三个速度环，使实际速度平滑跟随目标。
2. D 项观察实际加速度，不对目标阶跃求导；若噪声大，先降低适合 50 Hz 物理步的滤波截止频率。
3. 再启用高度与水平位置 P 外环，让位置误差生成有限目标速度。
4. 测试起飞、接地和停桨时积分与导数历史重置；空中切档不得重置。
5. 增加载荷并观察短暂下沉、积分补偿和推力饱和。

### 5. 轨迹整形与防摆

1. Attitude 环稳定后，让水平速度误差生成有限目标倾角。
2. 平移输入以当前真实机头为坐标系。验证运动档持续按 `Q` 10 秒、按 `E` 1 秒后立即按 `W`，蓝色目标速度应马上指向当前机头前方，不应等待旧航向目标追平。
3. 高速前飞后单独按 `Q` 两秒，再长按 `W`；Pitch/Roll 与 Yaw 外环应保持解耦，允许一次连续转弯侧倾，但不应出现左右交替侧倾并逐渐衰减的蛇形摇摆。
4. 先调速度环的刹停，再启用位置锁定；随后依次调 Profile 的加速度、Jerk、垂直加减速度和偏航角加速度。
5. 输入松开后只通过控制链减速，禁止直接清零 Rigidbody velocity。
6. 先调单摆被动阻尼比，默认 `0.35`；稳定悬停下约 20° 初始摆角应在 5 秒内衰减到 3° 以下。最后启用主动防摆，默认约 `18%`，确认只降低残余摆幅且不与飞控争抢横向控制。

## 必须观察的遥测

- FixedDeltaTime 和控制循环实际调用频率。
- 目标/实际 Roll、Pitch、Yaw 或姿态误差。
- 目标/实际机体角速度。
- 每轴 Error、P、I、D、RawOutput、ClampedOutput、IsSaturated。
- 四电机 Command、响应后输出、推力和反扭矩。
- 高度、垂直速度、水平速度、目标位置。
- Rigidbody mass、总载荷、重心和理论悬停推力。
- 是否接地、Armed 状态、故障原因和 NaN/Infinity 保护触发次数。

运行时按 `F3` 显示/隐藏飞控调试面板；面板使用中文主标签显示三轴速度 PID、三轴 Rate PID、目标/实际角速度、目标/可实现力矩、逐轴饱和、Yaw 保留比例、防摆修正、四电机与吊挂状态。编辑器 Game 视图还会绘制单旋翼升力、实际总升力、重力、实际/目标速度、目标加速度、目标推力、可实现合力和目标力矩，不依赖 Gizmos 开关。按 `F4` 会复制最近 500 个 FixedUpdate 样本的速度/姿态误差、逐轴饱和、Yaw 降权、输入响应延迟和摆幅包络。

载重调校时同时观察动力模式、额定载重、当前真实载荷、地面支持力、承载比例、飞控承载载荷、最大允许载荷、主刚体质量、机载抓斗恒定总质量、当前悬挂设备质量、吊索绷紧/摆角/摆速、软约束接入、当前受支持总质量、理论悬停指令和动力余量。

## 常见问题

### 一解锁就翻转

- 检查 Rotor Transform 顺序、位置和局部 `+Y`。
- 检查 Mixer 的 Roll/Pitch 符号。
- 检查模型前向是否与 `+Z` 约定一致。
- 不要先反转 PID 参数。

### 高频抖动

- Rate P 过高、D 噪声过大、Motor 响应过快或 fixedDeltaTime 不稳定。
- 检查输出是否逐帧打满上下限。
- 先调局部控制参数，不修改全局 solver iterations。

### 缓慢来回摆动

- 外环增益过高、内环太慢或积分过强。
- 临时禁用外环，确认 Rate/Attitude 各层独立稳定。

### 挂载后持续下沉

- 检查最大总推力与新总重量的比值。
- 地面抓取时先确认 F3 为“地面支撑”，地面支持力应接近载荷重量、承载比例接近 `0`；只有支持力下降并离地后才进入“离地接管”。
- 如果仍在地面就接入完整载荷，检查 Collision impulse、地面法线、外部支撑 Collider 数以及机体/抓斗/爪体 Collider 忽略绑定。
- 检查当前卷扬长度对应的单摆 Joint 两侧锚点是否重合；正常运行必须保持 Projection 关闭，不能用瞬时投影掩盖部署或抓取锚点误差。
- 检查高度/垂直速度积分是否被过早限幅。
- 推力重量比不足时应报告超载，不应提高重力补偿作弊。

### 释放载荷后持续上升

- 检查高度 setpoint 是否在释放瞬间被错误更新。
- 检查积分抗饱和和载荷变化后的积分处理策略。
- 允许由残余电机 RPM 产生短暂上窜，但必须由同一高度环恢复；不允许增加脚本冲量或直接修改速度。上窜持续时间由电机响应和高度环共同决定，不要求与卷扬放出动画等时长。

### Joint 抖动或爆炸

- 检查连接点是否重叠、质量比是否极端、Collider 是否初始穿透。
- 若无人机在抓斗收纳状态下一进场就翻倒，检查唯一单摆 Joint 是否已断开 `connectedBody`，抓斗是否为 Kinematic 且碰撞关闭。
- 放出时必须先按当前吊索长度对齐抓斗共同锚点，再连接唯一 Joint 并恢复动态物理；抓斗要继承挂点点速度和机体角速度。
- 抓取第一物理步若物体跳向抓斗中心，检查软约束两端是否使用同一个世界接触质心、初始弹簧是否为零、角度是否 Free、Projection 是否 None。
- 优先调整单摆阻尼比、最大阻尼扭矩、软约束接入时间和局部 solver override。
- 不先改变项目全局 Physics 设置。

### 抓斗水平连续转圈或长期不收敛

- 确认机构只有抓斗根一个动态 Rigidbody 和一个 `ConfigurableJoint`；不得残留连接节刚体、底座二级 Joint、六爪 HingeJoint。
- 单摆 Joint 主轴为局部 `+Y`、副轴为局部 `+Z`，默认扭转 `±25°`、摆角 `45°`、Projection None。
- F3 稳定下垂时摆角应接近 `0°`；若显示接近 `180°`，说明摆角参考方向错误。长期摆动先检查阻尼比和最大阻尼扭矩，再检查主动防摆是否过强。
- 需要更自由的摆动时只提高摆角；不要把扭转限位调到接近 `180°`，也不要增加串联关节。

## 裸机 MVP 验证方式

统计口径在首次实现自动工况时固定。目前目标为：

- 水平起飞到 1.5 m，稳定段连续 10 s 无触地、翻转或非法数值。
- 稳定段 95% 样本满足高度误差绝对值 ≤ 0.20 m、Roll/Pitch 误差绝对值 ≤ 3°。
- 水平冲量后 6 s 内回到高度 ±0.25 m、Roll/Pitch ±5°。
- 增加机体质量 20% 的中心载荷后 8 s 内回到高度 ±0.30 m。
- 释放载荷后允许短暂上窜，但控制量有限并能恢复。

阈值修改必须附实测曲线、统计窗口和理由，并同步更新模块文档与实施计划。

Unity 自动化测试按 [运行 Unity 自动化测试](./run-unity-tests.md) 执行；不得使用 dotnet/msbuild 或另起 BatchMode Unity。

## 当前操作键位

- `F`：从 Waiting 直接进入第三人称 Active；不会自动解锁或起飞。
- `Esc`：退出无人机接管并恢复玩家 Camera。
- `T` / `G`：自动起飞 / 自动降落。
- `R`：Active 中短按解锁/锁定；持续按住达到配置时间后显示 Loading，并完整卸载、重新加载当前 DroneFlight 场景。
- `WASD`：水平移动；`Q/E`：偏航；`Space/左 Ctrl`：升降。
- `1/2/3`：平稳（Cine）/ 普通（Normal）/ 运动（Sport）。
- `C`：循环无人机视角；方向键：云台/环绕；`-`/`=`：FOV。
- `L`：手动收放起落架；`J`：卷扬放出/收回；`H`：六爪闭合抓取/张开释放（必须先放出）；`F3`：右下角中文调试面板；`F4`：复制最近约 10 秒遥测摘要；`Backspace`：返回 Hub。

## 配置 Inspector 语言

1. 选择 `Assets/LoadResources/Demos/drone_flight/Data/DroneFlightConfig.asset`。
2. 在 Inspector 顶部选择“中文”或 “English”，再用“普通设置 / 高级设置”切换策划视图和完整底层视图。
3. 语言与分页偏好只保存在本机 `EditorPrefs`，不会产生配置资产差异；参数修改仍支持 Undo，并按 Unity 标准流程 Apply。
4. Play Mode 修改额定载重、倍率、满载占用、响应速度、机体倍率、最大 RPM 或自动/手动模式后，在下一个安全物理步生效；不会清零 RPM、PID、速度或位置。
5. 推荐默认值为额定载重 `1 kg`、最大载荷倍率 `1.25`、满载动力占用 `90%`、电机响应速度 `70`、机体质量倍率 `1.2`。

## 载重对比试飞

1. 保持 Normal Profile 不变，额定载重设为 `1 kg`，抓取 `0.95 kg` 测试物，记录 F3 理论悬停指令与动力余量。
2. 释放载荷时不要期待脚本弹跳；载荷应自由下落，无人机因残留 RPM 自然短暂上窜，再由高度 PID 恢复目标。当前测试只保证存在自然短暂上窜并能恢复，不人为锁定为“几秒”。
3. 将额定载重改为 `10 kg`，仍抓同一 `0.95 kg` 测试物。理论悬停指令应显著降低，但空载 Normal 目标速度不变。
4. 只修改最大载荷倍率，已抓取同一物体的理论悬停指令不应变化；只有抓取门禁上限变化。
5. 超过额定载重但未超过最大允许载荷时属于“超额区”，允许运输但余量更低；超过最大允许载荷应拒绝且不得残留 Joint。

手柄采用 Mode 2：左摇杆 Y/X 为升降/偏航，右摇杆 Y/X 为前后/左右。实体手柄仍必须在目标机器上手动确认死区、摇杆方向和操作手感。

## 当前人工试飞清单

1. 在地面按一次 `F`，确认立即进入第三人称且仍为锁定状态。
2. 按 `T` 自动起飞；分别用 Cine / Normal / Sport 检查悬停漂移、松杆刹停、偏航和高度响应。
3. 用 `WASD`、`Q/E`、`Space/左 Ctrl` 做短促与持续输入，观察是否出现高频抖动、缓慢摆动或长期电机饱和。
4. 用 `L` 手动收放四支腿；按 `J` 放出吊链，再用 `H` 让至少三个爪真实接触载荷，检查横飞/急停摆动、运输和释放后的恢复。
5. 按 `L` 验证起落架只手动切换；短按 `R` 验证解锁，随后长按达到配置时间，确认 Loading 出现且 DroneFlight 场景被完整卸载并重新加载。载荷、约束、HUD 和 Waiting 状态必须来自新的场景实例，而不是逐项复位旧对象。
6. 抓斗收纳时对比正常飞行手感；按 `J` 放出后观察单一抓斗沿无质量吊索自然摆动且逐渐衰减，再用 `H` 验证六爪动画、真实碰撞与三爪接触门禁。
7. 按 `J` 后确认机腹结构有连续放出动画，约 1 秒后 HUD 由“放出中”变为“已放出”；此时 `H` 必须能够开合六爪。空载再次按 `J` 应有连续收回动画并回到“已收纳”。
8. 打开 F3，确认 Game 视图中各矢量方向和数值随倾斜、加减速与偏航实时变化。
9. 抓斗放出后分别空载和带载横飞、急停至少 10 秒。允许单摆自然摆动，但 20° 左右残余摆幅应在约 5 秒内降到 3° 以下，不能长期恒幅或由主动防摆诱发机体左右振荡。
10. 让载荷停在地面并闭合六爪：真实载荷应立即显示，但地面支持力仍接近重量、承载比例接近 `0`；缓慢升高后应平滑进入“离地接管/空中承载”。再落地但保持闭爪，应显示“落地卸载”并平滑回到 `0`。

如抓斗资源需要重建，执行 `Tools > SleepyDemos > DroneFlight > 重建工业六爪与场景绑定`。工具会生成低模 Mesh/材质、重建 Prefab 并重绑场景显式引用；执行后必须重新运行本模块精确测试。
6. 出现异常后保持飞行约 10 秒并按 `F4`，保存剪贴板摘要；同时记录所用 Profile、操作和主观现象，作为下一轮恢复任务的输入。
