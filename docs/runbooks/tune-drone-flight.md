# 调试和整定 DroneFlight

## 适用场景

- 首次让基础几何体四旋翼稳定起飞。
- 修改质量、机臂长度、电机、Rotor 位置或控制参数。
- 排查高频振荡、缓慢摆动、漂移、推力饱和、挂载下沉或 Joint 抖动。

本 runbook 随实现逐阶段完善。当前只定义裸机 MVP 的调参顺序、必须遥测和验收口径，不提供未经实测的“万能 PID 参数”。

## 前置条件

- Unity 打开的是 `SleepyDemos` 和 DroneFlight 测试场景。
- Rigidbody 质量、重心、Collider 和四个 Rotor Transform 已确认。
- 固定物理步长保持基线 `0.02 s`，没有先修改全局 Physics Solver。
- 无风、无载荷、水平地面，机体以零速度和水平姿态开始。
- 调试面板显示目标值、实际值、误差、P/I/D、输出和饱和状态。

## 调参顺序

### 1. 先验证物理和符号

1. Disarmed 时确认四电机推力为零。
2. 仅增加 Collective，四电机应等量增加。
3. 分别给正 Roll/Pitch/Yaw 小命令，核对四电机增减方向。
4. 确认推力箭头沿每个 Rotor 局部 `+Y`，反扭矩旋向与配置一致。
5. 确认悬停总推力理论值约为 `mass * 9.81 N`，并且最大总推力高于重量。

任一符号错误时先修 Mixer/Rotor 配置，禁止通过负 PID 参数“调回来”。

### 2. Rate 环：P → D → I

1. 禁用外层姿态、高度和位置环。
2. `I=0`、`D=0`，从小到大增加 P，使实际角速度能够快速跟随目标。
3. 若出现持续高频振荡，降低 P；不要先增加 Rigidbody angular drag。
4. 增加 D 抑制超调和快速振荡，同时观察 D 项噪声与滤波。
5. 最后增加少量 I，消除稳态偏差，并验证输出饱和时积分不会 wind-up。
6. Pitch、Roll 分别验证；只有机体完全对称时才共享参数。Yaw 单独调节。

### 3. Attitude 环

1. Rate 环稳定后再启用姿态环。
2. 从小目标角开始，确认 Quaternion 最短旋转方向正确。
3. 增加姿态增益，直到回正速度合适且不会把 Rate 环推入长期饱和。
4. 测试接近 ±180° Yaw 和中等 Pitch/Roll，不得出现 Euler 跨界跳变。

### 4. 垂直速度和高度环

1. 使用 `mass * gravity` 作为悬停前馈，先让垂直速度目标为零。
2. 调垂直速度环，使推力扰动后速度平滑回零。
3. 再启用高度外环，让高度误差生成有限目标垂直速度。
4. 测试起飞、接地和停桨时积分重置。
5. 增加中心载荷并观察短暂下沉、积分补偿和推力饱和。

### 5. 水平速度和位置环

1. Attitude 环稳定后，让水平速度误差生成有限目标倾角。
2. 先调速度环的刹停，再启用位置锁定。
3. 输入松开后只通过控制链减速，禁止直接清零 Rigidbody velocity。
4. 最后分别配置 Cine、Normal、Sport 的速度、加速度、倾角和输入变化率。

## 必须观察的遥测

- FixedDeltaTime 和控制循环实际调用频率。
- 目标/实际 Roll、Pitch、Yaw 或姿态误差。
- 目标/实际机体角速度。
- 每轴 Error、P、I、D、RawOutput、ClampedOutput、IsSaturated。
- 四电机 Command、响应后输出、推力和反扭矩。
- 高度、垂直速度、水平速度、目标位置。
- Rigidbody mass、总载荷、重心和理论悬停推力。
- 是否接地、Armed 状态、故障原因和 NaN/Infinity 保护触发次数。

运行时按 `F3` 显示/隐藏飞控调试面板；面板逐轴显示 Rate 目标值、实际值、误差与 P/I/D，并同时显示四电机、总推力和 FixedDeltaTime。按 `F4` 会把最近 500 个 FixedUpdate 样本（默认约 10 秒）的摘要复制到系统剪贴板；摘要用于对比高度误差、最大倾角、最大水平速度、饱和次数和非法值次数，不会修改飞控状态。

## 常见问题

### 一解锁就翻转

- 检查 Rotor Transform 顺序、位置和局部 `+Y`。
- 检查 Mixer 的 Roll/Pitch 符号。
- 检查模型前向是否与 `+Z` 约定一致。
- 不要先反转 PID 参数。

### 高频抖动

- Rate P 过高、D 噪声过大、Motor 响应过快或 fixedDeltaTime 不稳定。
- 检查输出是否逐帧打满上下限。
- 先调局部控制参数，不修改全局 solver iterations。

### 缓慢来回摆动

- 外环增益过高、内环太慢或积分过强。
- 临时禁用外环，确认 Rate/Attitude 各层独立稳定。

### 挂载后持续下沉

- 检查最大总推力与新总重量的比值。
- 检查高度/垂直速度积分是否被过早限幅。
- 推力重量比不足时应报告超载，不应提高重力补偿作弊。

### 释放载荷后持续上升

- 检查高度 setpoint 是否在释放瞬间被错误更新。
- 检查积分抗饱和和载荷变化后的积分处理策略。
- 允许短暂上窜，但必须由同一高度环恢复。

### Joint 抖动或爆炸

- 检查连接点是否重叠、质量比是否极端、Collider 是否初始穿透。
- 优先调整 Joint 局部参数和载荷结构，再评估局部 solver override。
- 不先改变项目全局 Physics 设置。

## 裸机 MVP 验证方式

统计口径在首次实现自动工况时固定。目前目标为：

- 水平起飞到 1.5 m，稳定段连续 10 s 无触地、翻转或非法数值。
- 稳定段 95% 样本满足高度误差绝对值 ≤ 0.20 m、Roll/Pitch 误差绝对值 ≤ 3°。
- 水平冲量后 6 s 内回到高度 ±0.25 m、Roll/Pitch ±5°。
- 增加机体质量 20% 的中心载荷后 8 s 内回到高度 ±0.30 m。
- 释放载荷后允许短暂上窜，但控制量有限并能恢复。

阈值修改必须附实测曲线、统计窗口和理由，并同步更新模块文档与实施计划。

Unity 自动化测试按 [运行 Unity 自动化测试](./run-unity-tests.md) 执行；不得使用 dotnet/msbuild 或另起 BatchMode Unity。

## 当前操作键位

- `F`：地面待机时开始拿起/开机/连接；进入 RT Preview 后再次按下切换 Fullscreen。
- `Esc`：退出无人机接管并恢复玩家 Camera。
- `T` / `G`：自动起飞 / 自动降落。
- `R`：手动解锁/锁定。
- `WASD`：水平移动；`Q/E`：偏航；`Space/左 Ctrl`：升降。
- `1/2/3`：Cine / Normal / Sport。
- `C`：循环无人机视角；方向键：云台/环绕；`-`/`=`：FOV。
- `H`：抓钩闭合抓取 / 张开释放；`F3`：飞控调试面板；`F4`：复制最近约 10 秒遥测摘要；`Backspace`：返回 Hub。

手柄采用 Mode 2：左摇杆 Y/X 为升降/偏航，右摇杆 Y/X 为前后/左右。实体手柄仍必须在目标机器上手动确认死区、摇杆方向和操作手感。

## 当前人工试飞清单

1. 在地面按 `F`，等待遥控器屏幕进入 RT Preview，再按一次 `F` 切换 Fullscreen。
2. 按 `T` 自动起飞；分别用 Cine / Normal / Sport 检查悬停漂移、松杆刹停、偏航和高度响应。
3. 用 `WASD`、`Q/E`、`Space/左 Ctrl` 做短促与持续输入，观察是否出现高频抖动、缓慢摆动或长期电机饱和。
4. 按 `C` 切换视角；用 `H` 抓取不同质量载荷，检查运输与释放后的下沉、上窜和恢复。
5. 出现异常后保持飞行约 10 秒并按 `F4`，保存剪贴板摘要；同时记录所用 Profile、操作和主观现象，作为下一轮恢复任务的输入。
